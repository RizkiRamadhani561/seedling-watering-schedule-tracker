# Seedling Watering Schedule Tracker

A tiny local-first watering tracker for your windowsill garden.

## 🌐 Live Demo
**[https://RizkiRamadhani561.github.io/seedling-watering-schedule-tracker/](https://RizkiRamadhani561.github.io/seedling-watering-schedule-tracker/)**

## Features
- Add plants with name and watering frequency
- Watered Today tracking with one click
- Overdue / Due Today / On Track detection
- Natural-language countdown ("Next watering in 3 days")
- Filter: All / Needs Water / On Track
- Search by plant name
- localStorage persistence (survives refresh and browser close)
- Responsive UI (mobile-first, 1–3 column grid)
- CSS animations, toast feedback, delete confirmation
- Zero external dependencies

## Tech
Vanilla HTML, CSS, JavaScript — single file, no build step.
